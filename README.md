# Гортензия · Мой сад (Android)

Исходный код офлайн-приложения по уходу за **гортензией метельчатой (Hydrangea paniculata)**. Интерфейс на русском языке, с адаптивной мобильной вёрсткой, встроенной в Android WebView. Android-оболочка написана на Kotlin, не использует сторонние библиотеки и не запрашивает доступ в интернет.

## Возможности

- «Сегодня»: сезонные задачи и подсказки, кому из кустов пора проверить влажность почвы.
- «Мой сад»: добавление, изменение и удаление растений; сорт, дата посадки, место, заметки.
- Запись событий: осмотр влажности, полив, подкормка, обрезка, мульчирование, история по каждому кусту.
- «Календарь»: 12 месяцев, отметка выполнения задач для каждого календарного года.
- «Справочник»: посадка, полив, почва, обрезка, подкормки, зимовка, защита и размножение; описание 12 сортов; подсказки по видимым проблемам листьев и цветения.
- Ежедневное напоминание **примерно в 09:00**, по желанию владельца, с системным разрешением Android 13+; это напоминание об осмотре, а не команда поливать.
- Резервная копия и восстановление своих записей в JSON через стандартный системный выбор файла.
- Данные хранятся локально, регистрации и облачного аккаунта не требуется.

**Важно:** сроки календаря ориентировочные для средней полосы; учитывайте местную погоду, сорт, возраст и состояние почвы. Ни одна функция не предписывает полив только из-за даты. Справочник переработан из предоставленного пользователем пособия «Пособие по выращиванию метельчатой гортензии (Hydrangea paniculata)»; это не фитопатологическая диагностика.

## Открыть и собрать APK в Android Studio

1. Распакуйте архив и откройте папку `Gortenziya_Moy_Sad` в **Android Studio** через **File → Open**.
2. Установите из **SDK Manager** Android SDK Platform 35. Для сборки проекта потребуются **JDK 17**, **Gradle 8.9**, Android Gradle Plugin 8.7.3 и Kotlin Gradle Plugin 2.0.21. При первом открытии IDE может скачать необходимые компоненты через интернет (само приложение интернета не требует).
3. В этом ZIP нет бинарного `gradle-wrapper.jar`. Если ваша IDE предлагает выбрать Gradle, укажите установленную версию **8.9**; при необходимости установите Gradle и один раз выполните в корне проекта `gradle wrapper --gradle-version 8.9`. Это создаст стандартные `gradlew`, `gradlew.bat`, `gradle/wrapper/*`.
4. Дождитесь синхронизации Gradle, затем выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Если используете командную строку после создания wrapper, выполните `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).
5. Готовый тестовый APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`. Устанавливайте через Android Studio на подключённый телефон или перенесите APK на устройство и установите с разрешением установки из выбранного источника, если это разрешено настройками устройства.

Минимальная версия Android: **6.0 (API 23)**. Целевая: Android 14 (API 34). Подписанный релизный APK / публикация в Google Play требуют вашего ключа подписи и отдельных действий.

## Предпросмотр без Android Studio

Можно открыть `app/src/main/assets/index.html` в браузере на компьютере: экран, карточки, календарь, заметки, экспорт и импорт работают как локальное веб-приложение. Системные Android-уведомления в браузерном предпросмотре не работают.

## Запуск тестов

Из корня проекта при установленном Node.js:

```sh
node tests/test_core.js
```

Тесты проверяют локальные даты, интервалы проверки почвы, ключи задач по году, валидацию резервной копии, наличие сезонного контента и рендер / переходы интерфейса. Тесты JavaScript не заменяют реальную сборку APK и проверку на Android-устройстве.

## Структура

- `app/src/main/assets/index.html` — контейнер интерфейса.
- `app/src/main/assets/style.css` — светлая зелёно-розовая тема.
- `app/src/main/assets/app.js` — экраны, формы, история ухода, резервные копии.
- `app/src/main/assets/core.js` — чистые функции и проверка данных импорта.
- `app/src/main/assets/content.js` — сезонный календарь и справочник.
- `app/src/main/java/ru/gortenziya/moisad/MainActivity.kt` — локальный WebView и системный выбор JSON-файла.
- `app/src/main/java/ru/gortenziya/moisad/ReminderReceiver.kt` — необязательные уведомления и восстановление расписания после перезагрузки.

**Ограничения первой версии:** нет онлайн-погоды, GPS, распознавания заболеваний по фото, общего аккаунта или синхронизации между устройствами. Изображение цветка создано в виде встроенной в интерфейс векторной иллюстрации. Перед удалением приложения сохраните резервную копию — вместе с приложением могут быть удалены и его локальные данные.
