# Гортензия — Мой сад 2.0 · распределение фото по сортам

## Реализовано в коде

- В приложении «Альбом» сначала показывает разделы сортов. Выбор из полного каталога доступен через список. В карточке сорта есть кнопка «Фото сообщества», открывающая **только его фотографии**. Отдельные фильтры: Telegram / пользователи.
- При отправке фото из личного дневника в общий альбом пользователь обязан выбрать один сорт из зарегистрированного каталога. После модерации снимок появляется только в разделе этого сорта. Публикации без известного сорта не смешиваются с другими.
- При ручной отправке фото в Telegram приложение прикладывает к подписи `#сорт_<ключ> #в_альбом` для известного сорта. **Системное меню Android само по себе не публикует снимки в канал; администратор самостоятельно размещает фото в канале.**
- Сервер получает новые фото из `@Gortenzium`, только если в подписи **ровно одна** распознанная метка `#сорт_<ключ>` и `#в_альбом`. Записи без метки, с неизвестным или несколькими сортами не импортируются. Имя сорта не угадывается по изображению.
- Файл Telegram сохраняется в `gortenzium-channel/Gortenzium/<ключ_сорта>/<id_поста>.jpg`, запись содержит `variety_key`. Изменение метки у уже синхронизированного поста перемещает зеркальную копию в новый раздел, но исходная публикация канала остаётся на месте. Удаление меток в отредактированном посте убирает зеркало. Удаление поста из Telegram **не** даёт bot-события удаления и требует удаления копии администратором из Supabase.
- Существующие записи v1.9 без сорта не переносятся в произвольный сорт. Их можно вручную классифицировать после проверки администратором и переместить файлы, или повторно опубликовать с метками.

## Как маркировать пост в канале

Пример для Limelight: `Мой Limelight, сентябрь #сорт_Limelight #в_альбом`

Для Little Lime: `Первое цветение #сорт_Little_Lime #в_альбом`

Для Самарской Лидии: `Гортензия зацвела #сорт_Самарская_Лидия #в_альбом`

Метки формируются на основе официального **встроенного списка** `supabase/functions/gortenzium-webhook/variety-catalog.mjs` (101 запись). При добавлении нового зарегистрированного сорта необходимо одновременно обновить `app/src/main/assets/variety_keys.js`, файл `variety-catalog.mjs` и `supabase/varieties_seed.sql`, а затем применить SQL. Не назначайте несуществующий сорт из догадки. Для пока неизвестных сортов сначала подтвердите и внесите название в общий справочник.

## Как установить обновление

1. Разверните прежнюю версию проекта Supabase по `supabase/SETUP.md` и `TELEGRAM_TWO_WAY.md`, если она ещё не была настроена. Не выполняйте базовый `setup.sql` повторно в существующей базе.
2. В SQL Editor подключённого Supabase исполните `supabase/variety_migration.sql`, затем `supabase/varieties_seed.sql`. Это создаёт индексы, колонку сорта, разделы и политику: новые публикации пользователей без выбранного зарегистрированного сорта сервер не принимает. Проверьте, что обе команды завершились без ошибок. **SQL применяйте до публикации новых фото/обновления APK**, иначе новые колонки отсутствуют.
3. Разверните обновлённую Supabase Edge Function `gortenzium-webhook`, сохранив прежние секреты Telegram/Supabase на стороне сервера. Проверьте действующий `setWebhook` и наличие бота среди администраторов канала.
4. Загрузите v2.0 в GitHub, дождитесь успешной сборки APK; приложение надо собирать с уже настроенными `SUPABASE_URL` и `SUPABASE_ANON_KEY` (не с секретным серверным ключом).
5. От имени администратора разместите в канале тестовую фотографию с **обеими** метками. Откройте приложение: Справочник → Limelight → Фото сообщества. Должна отобразиться одна и та же публикация, только в разделе Limelight. Затем проверьте другой сорт.
6. В приложении отправьте фото на модерацию, выбрав сорт из списка. После одобрения в Supabase обновите альбом, откройте соответствующий раздел. Это направление **пока не публикует фото автоматически в Telegram** — при необходимости администратор отправляет проверенный снимок в канал вручную.

### Особенность канала и форумных тем

`@Gortenzium` сейчас не удаётся проверить на предмет реальной организации сортовых разделов. **Этот релиз маршрутизирует по явной метке сорта в посте канала, а не по Telegram `message_thread_id`**. Bot API передаёт `message_thread_id` для тем супергрупп, а не обычных публикаций канала. Если ваши сорта организованы именно в темах связанной супергруппы, пришлите скриншот списка тем и одну ссылку на пост из темы: для точного соответствия потребуется отдельное отображение `chat_id + message_thread_id → variety_key`, подключение бота к группе и проверка настроек доступа. Не привязывайте фото по случайному совпадению названия темы.

### Приватность

Никакие персональные фотографии не отправляются автоматически в публичный канал. Перед добавлением фото в канал администратор должен получить согласие автора на повторное размещение и проверить отсутствие лиц, адресов и личных данных. Секреты и bot token не добавляются в APK или GitHub.
